# 11 風險、限制與授權

這份文件整理 LedgerLand 從規劃到公開上線的主要風險、目前已知而且決定接受的限制，以及程式碼與教學內容的授權。風險登記表的每一列都寫出可能性、影響、緩解措施、要在哪個里程碑處理，以及相關的待確認編號；各項緩解措施的細節分散在其他文件，這裡只寫重點並標出處。D 系列已在 2026-10-20 全部決定，風險與限制都已照決定更新；授權（D6）定為程式碼 MIT、原創教學內容 CC BY-SA 4.0，老師的故事情境與金額另外標示「經陳彥宏老師授權使用」，第 4 節保留取捨紀錄並寫出落實方式。

### 4.3 教學內容：CC BY-SA 4.0（已決定）

中文名稱分別是「創用 CC 姓名標示-相同方式分享 4.0 國際」與「創用 CC 姓名標示-非商業性-相同方式分享 4.0 國際」。創用 CC 官方不建議用 CC 授權軟體，所以程式碼與內容分開授權。

| 比較 | CC BY-SA 4.0 | CC BY-NC-SA 4.0 |
| --- | --- | --- |
| 商業使用 | 允許，但必須署名，改作也必須以相同授權分享 | 不允許商業使用 |
| 開放程度 | 屬於「自由文化」授權，可以和維基百科等 BY-SA 內容互相引用 | 不屬於自由文化授權；有些開放教育資源平台不收 NC 內容 |
| 「非商業」的界線 | 不需要判斷 | 界線模糊：補習班、收費課程、有廣告的網站算不算商業，常有爭議，反而讓想合法使用的學校或老師卻步 |
| 與其他素材混用 | 可以納入 CC BY 與 CC BY-SA 的素材 | 可以納入 CC BY、CC BY-NC 與 CC BY-NC-SA 的素材，但不能納入 CC BY-SA 的素材；反過來，NC-SA 的內容也不能放進 BY-SA 的作品 |
| 防止封閉 | ShareAlike 讓改作版本也必須開放 | 同左，另外防止他人直接拿去販售 |
| 回應老師可能的顧慮 | 若老師不希望課程衍生的內容被商業補習班使用，可能不夠 | 比較能回應這類顧慮 |
| 日後更改 | 已經以 BY-SA 發布的版本，別人可以一直依 BY-SA 使用，無法收回 | 從 NC 放寬為 BY-SA 比較容易（只要所有著作權人同意） |

已決定（D6，2026-10-20）：原創教學內容採 CC BY-SA 4.0；老師的故事情境與金額不在 CC 授權內，標示「經陳彥宏老師授權使用」。理由是 BY-SA 屬於自由文化授權，可以和其他開放教材互相引用，ShareAlike 也讓改作版本必須開放。未採用的選項：CC BY-NC-SA 4.0（「非商業」的界線模糊，部分開放教育平台不收 NC 內容，也不能和 BY-SA 素材混用）；CC BY 4.0（改作版本可以不開放）。

老師可能的顧慮（課程衍生的內容被商業補習班使用）主要落在老師的故事素材上，而這部分本來就不在 CC 授權內，別人要重用必須另外取得老師同意。授權一旦發布就無法收回：已經以 BY-SA 發布的版本，別人可以一直依 BY-SA 使用。D6 是最終決定：原創內容採 CC BY-SA 4.0；【待確認 T34】若一併問到老師對商業使用的態度，回覆只作參考，不再改變內容授權。

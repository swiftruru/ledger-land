開工時我另外決定四件事（2026-11-07，寫在 [14 待確認](../plan/14-open-questions.md) 第 5.2 節）：

1. **來源面板的形式**：用既有的 `Sheet`（手機底部面板、768 以上置中 640 寬，`.ll-sheet--trace`）。未採用：[02](../plan/02-site-architecture.md) 第 3.4 節的電腦右側停靠面板（新版面、CSS 約 1.5 KB、多一個無障礙面）。

IFRS 18 的核對：10 第 11.2 節要求實作 IFRS 說明前先核對 IFRS 18 對 IAS 7 的修正。名詞卡標了查證日期 2026-10-24，沒有留下公告或條號的出處，M4b 沒有重新核對準則原文（第 9 節）；台灣的適用年度依名詞卡，出處待核對。M4b 沒有新增 IFRS 說明段落，只多一句標示依據的準則版本。[11 風險與授權](../plan/11-risks-license.md) 第 2.1 節的文字這次才同步。

## 6. 和計畫不同的地方

- **計畫以外的修正範圍**：計畫裡 PR D 只有回報與文件。收尾時我先做完整的規格稽核，發現的缺陷（第 2 節）直接放進同一個 PR 修，沒有另開 PR，所以這個 PR 除了文件也動了實驗室的程式、測試與字串。

## 8. 新發現

- **闖關地圖的 `.qm-sticky` 蓋住焦點**：節點與章節連結用 Tab 走到時，有些會鑽到固定的頂列底下。既有問題，不在本次範圍；新加的檢查只量 `ll-lab-` 開頭的列，所以它沒有擋下來，也還沒修。
- **WebKit 動態 import 失敗後不重試**：WebKit 把失敗的動態 import 記在文件的模組表，再 import 同一個網址不發請求（2026-11-07 實測）。所以來源面板重試一次仍失敗就換成「重新載入」（`TraceLoadToast`，階段的 ErrorState 也一樣）。之後其他懶載入的模組要做「再試一次」，也要考慮這一點。
- **`i18n:check` 抓不到佔位符不符**：它只查缺字。英文 catalog 有 5 條字串的佔位符和原始碼不同（`lab.scale.summary`、`lab.sandbox.range`、`lab.sandbox.blocked`、`lab.sandbox.rangeDownstream`、`lab.sandbox.rangeDownstreamAccount`），執行時那個位置變成空白，例如被擋下的訊息少了上下限。已修，並加 `apps/web/test/catalog-placeholders.test.ts` 比對兩份 catalog。
- **CI 全綠不等於有涵蓋**：PR 115 的 CI 全綠，但 axe 從 M4a 起只掃 `/lab/` 一頁，實驗室其他畫面一直沒有被掃；M4a 回報也寫錯。之後回報要對照測試實際列的頁面，不只看綠燈。
- **報表變動列底色上的 `danger-ink`** 在莓果 4.34、紅酒 4.37；之前 `contrast.test.ts` 沒有這組配對，axe 又沒掃，所以一直沒發現。
- **IFRS 算不下去的路徑走不到**：核心掃過拿掉單步、覆寫 0 到 50 倍、每個範本插到每一步、組合與移動，都找不到教材成功而 IFRS 失敗的情況。`lab.policy.ifrsFailedAt`、`lab.policy.ifrsFailedStep` 兩句只有 `sandboxView` 的單元測試。
- **反方向可以發生**：教材擋下、IFRS 不擋。L3 的前置條件讓設立費改成 0 或刪除第 5 步時教材被下游擋下，`ifrs@1` 仍成功。

## 9. 已知限制

追蹤：

- 「點任何數字」沒有到字面的任何數字：交易前欄、五層利益表、勾稽燈號的兩個數字、天平、本筆變動摘要列、指標的交易前數字都不能點。範圍依 03 第 3.9 節。
- 跨表連線維持外框，不畫線（M4a 已知限制）。連線的文字只在 live region，畫面沒有可見文字。
- compact 一次只顯示一張表：標出後看得到的只有另一張表那一列，另一列由 live region 說明。
- 自由實驗與指標實驗室沒有「在報表上標出」鈕，只有文字。
- 公式句是符號版（「＋」「－」），怎麼唸要實機確認。
- 科目部分合成一列（例如「未分配盈餘科目」），明細在來源步驟。
- 「開啟這一步」是到故事原本那一步的練習模式：來源就是目前這一步時沒有按鈕（本筆變動視窗因此沒有）；從自由實驗開啟時，自由實驗的修改不帶過去。
- 練習模式下，步驟頁頂端的恆等式從階段 1 起是交易後的數字，也點得開面板，預測之前就看得到本步來源（讀程式得到的，沒有實測）。

IFRS 對照：

- `labView` 的 `window`、`statement` 不讀不寫：每一步都回到累計與損益表。
- 差異標記不能點開名詞卡的「IFRS 怎麼處理」段落。
- `ifrs@1` 版面的中文列名只換了一部分：可見且有名詞的列中，有 34 列仍用教材字，和名詞的現行用語不同（只看和 `teacher@1` 同字則有 91 條，見 04 第 10.3 節）；實質差異集中在現金流量表，版面與名詞的用語沒有測試比對。
- 「設立費」（`is_organisation_costs_expense`）不在上面的 34 列裡：名詞 `tm_hz08w4k5` 的 `currentTwLabel` 是空的，但 [12 術語表](../plan/12-glossary.md) 標的現行用語是開辦費。IFRS 對照的差異就在這一列，用的卻是教材字（第 12 節）。
